Get started with SCDOSCDO 新手入门

Shard0 is the SCDO main chain: an EVM-compatible proof-of-work chain (chain ID 5680) that works with MetaMask and other Ethereum wallets. Shards 1–4 are the archived legacy chains; their history stays searchable on this explorer.

Shard0 是 SCDO 主链：兼容 EVM 的工作量证明（PoW）链（Chain ID 5680），可直接使用 MetaMask 等以太坊钱包。Shard 1–4 为已归档的旧链，其历史数据仍可在本浏览器中查询。

1Set up your wallet设置钱包

MetaMask (browser extension)（浏览器插件）

  1. Install MetaMask from metamask.io and create or import a wallet. Write your Secret Recovery Phrase on paper and keep it offline.
  2. Click Add SCDO to MetaMask above and approve the request in MetaMask.
  3. MetaMask switches to SCDO Mainnet (Shard 0). Your address (starts with 0x) is the same as on any EVM chain.
  1. 从 metamask.io 安装 MetaMask，创建或导入钱包。请把助记词抄在纸上并离线保管。
  2. 点击上方 一键添加 SCDO 到 MetaMask，在 MetaMask 弹窗中确认。
  3. MetaMask 会切换到 SCDO Mainnet (Shard 0)。你的地址（以 0x 开头）与其他 EVM 链上的地址相同。

MetaMask (mobile app)（手机 App）

  1. Open this page inside the MetaMask app browser: open in MetaMask.
  2. Tap Add SCDO to MetaMask and approve.
  3. Or add it by hand: Settings → Networks → Add network → Add a network manually and paste the parameters from section 2.
  1. 在 MetaMask App 内置浏览器中打开本页：用 MetaMask 打开。
  2. 点击 一键添加 SCDO 到 MetaMask 并确认。
  3. 或手动添加：设置 → 网络 → 添加网络 → 手动添加网络，填入第 2 节的参数。

Trust Wallet

  1. Open Trust Wallet and go to Settings → Networks (in some versions: the network selector → Add custom network).
  2. Tap + / Add custom network and enter the parameters from section 2 (RPC URL, chain ID 5680, symbol SCDO, explorer).
  3. Save, select SCDO, and copy your 0x address from the receive screen.
  1. 打开 Trust Wallet，进入 设置 → 网络（部分版本为：网络选择器 → 添加自定义网络）。
  2. 点击 + / 添加自定义网络，填入第 2 节参数（RPC URL、Chain ID 5680、符号 SCDO、区块浏览器）。
  3. 保存并选择 SCDO，在“收款”页面复制你的 0x 地址。

Menu names differ between app versions. Other EVM wallets (Rabby, OKX Wallet, imToken, …) work the same way with the parameters below.

不同版本的菜单名称可能略有差异。其他 EVM 钱包（Rabby、OKX Wallet、imToken 等）使用下方参数同样可以添加。

Stay safe安全提示

  • Never share your Secret Recovery Phrase or private key. scdoscan.io will never ask for it.
  • Check that the RPC URL is exactly https://scdoscan.io/rpc/0.
  • SCDO shard0 moved to chain ID 5680 on 2026-09-28 (the old ID 568 belongs to “Dogechain Testnet” in public registries). If you added SCDO earlier with chain ID 568, delete that network in your wallet and add it again with the values on this page.
  • 切勿泄露助记词或私钥。scdoscan.io 永远不会向你索取。
  • 请确认 RPC URL 为 https://scdoscan.io/rpc/0。
  • SCDO shard0 已于 2026-09-28 改用 Chain ID 5680（旧 ID 568 在公共注册表中属于“Dogechain Testnet”）。如果你之前用 Chain ID 568 添加过 SCDO，请在钱包中删除该网络，并按本页参数重新添加。

3View your address on the explorer在浏览器中查看你的地址

Paste your 0x address (or connect your wallet) to see its shard0 balance and open it on scdoscan.io. You can also paste an address or transaction hash into the search box on the homepage.

粘贴你的 0x 地址（或连接钱包），即可查看 shard0 余额并在 scdoscan.io 中打开。也可以在首页搜索框中输入地址或交易哈希。

4Faucet (small amount for fees)水龙头（少量手续费）

New addresses can claim a small amount of SCDO (currently 0.01 SCDO) to pay transaction fees while trying the network. Limit: one claim per address every 24 hours and one per IP address every hour.

新地址可领取少量 SCDO（目前为 0.01 SCDO），用于体验网络时支付交易手续费。限制：每个地址 24 小时 1 次，每个 IP 每小时 1 次。

Mining and running nodes are how SCDO is secured: miners produce proof-of-work blocks and independent nodes verify them. See the Mining & Nodes page for the current status, the legacy guide and the Downloads section (node packages coming soon).

Legacy shards 1–4 (archived)旧分片 1–4（已归档）

  • Shards 1–4 are the original SCDO chains. They are archived: kept for history and lookups, not the place for new activity.
  • Legacy addresses look like 1S01… / 2S02… and amounts use 8 decimals. They are not MetaMask/EVM addresses.
  • Search a legacy address or transaction on the explorer homepage and pick the shard in the shard bar.
  • Shard 1–4 是 SCDO 最初的链，现已归档：保留历史数据供查询，不建议用于新的活动。
  • 旧地址形如 1S01… / 2S02…，金额为 8 位精度，不是 MetaMask/EVM 地址。
  • 可在浏览器首页搜索旧地址或交易，并在分片栏中选择对应分片。
