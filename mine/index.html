Mining & nodes: securing the network挖矿与节点：守护网络安全

SCDO is a proof-of-work chain. Miners bundle transactions into blocks and make the chain's history expensive to rewrite; independent nodes check every block and serve the network. Both keep SCDO open and verifiable.

SCDO 是工作量证明（PoW）链。矿工把交易打包成区块，使链上历史难以被篡改；独立节点校验每一个区块并为网络提供服务。二者共同保证 SCDO 的开放与可验证。

Shard0 (main chain)（主链） Live

Shard0 is the SCDO main chain: a real Ethash proof-of-work EVM chain (chain ID 5680) running on core-geth, the Ethereum Classic client. Anyone with a GPU can mine it and anyone can run a full node that verifies every block. See Mine shard0 with a GPU.

Shard0 是 SCDO 主链：运行在 core-geth（以太坊经典客户端）上的真实 Ethash 工作量证明 EVM 链（Chain ID 5680）。任何人都可以用 GPU 挖矿，也可以运行校验每个区块的全节点。详见用 GPU 挖 shard0。

You can already use shard0 today with MetaMask through the public RPC: Get Started →

现在即可通过公共 RPC 用 MetaMask 使用 shard0：新手入门 →

Mine shard0 with a GPU用 GPU 挖 shard0

Algorithm Ethash (same as pre-merge Ethereum, 30,000-block epochs, not etchash) · chain ID / network ID 5680 · P2P port 30368 · block target ~13 s · epoch-0 DAG ≈1 GB. You mine through your own node, so block rewards go to the address you choose.

算法 Ethash（与合并前的以太坊相同，每 30,000 块一个纪元，不是 etchash）· Chain ID / Network ID 5680 · P2P 端口 30368 · 目标出块约 13 秒 · 纪元 0 的 DAG 约 1 GB。通过你自己的节点挖矿，出块奖励进入你指定的地址。

  1. Easiest – Windows + NVIDIA GPU (RTX 20/30/40/50 series): download scdo-shard0-gpu-miner-windows-amd64.zip, unzip to e.g. C:\scdo-miner, add that folder as a Windows Defender exclusion (every GPU miner is flagged as a “potentially unwanted app”), open start-mining.bat in Notepad, set set WALLET=0x… to your address and double-click it. It starts a local core-geth node (rewards to your address) and a small stratum proxy, downloads the NVIDIA miner Rigel 1.23.2 from its official release (SHA256-checked; closed source, 0.7% dev fee) and starts mining once the node has synced. Linux: scdo-shard0-gpu-miner-linux-amd64.tar.gz, WALLET=0x… ./start-mining.sh.
  2. Manual / other miners: initialise once with ./core-geth-scdo-linux-amd64 --datadir ./scdo0 init scdo-shard0-genesis.json, run the node without --mine:
    ./core-geth-scdo-linux-amd64 --datadir ./scdo0 --networkid 5680 --port 30368 --syncmode full --bootnodes enode://1d2c370db7c419349e2313f20023f6b379f946990042b9b42df45cb56e4c3487df0d36c52cd81308fcdf312450f758a6213fcac21213e94a71af4a3c9392601f@82.223.19.88:30368 --http --http.addr 127.0.0.1 --http.port 8545 --http.api eth,net,web3,miner --miner.etherbase 0xYOUR_ADDRESS
    then the proxy from the package, which starts getwork mining only after the node has synced:
    ./scdo-stratum -rpc http://127.0.0.1:8545 -listen 127.0.0.1:3333 -autostart -ref-rpc https://scdoscan.io/rpc/0
    and point any Ethash stratum miner at 127.0.0.1:3333, e.g. rigel -a ethash -o ethproxy+tcp://127.0.0.1:3333 -u 0xYOUR_ADDRESS or lolMiner --algo ETHASH --pool 127.0.0.1:3333 --user 0xYOUR_ADDRESS --ethstratum ETHPROXY.
  3. Do not mine before your node has synced: a fresh node would otherwise build its own chain from the genesis block. getwork miners such as ethminer can still use http://127.0.0.1:8545, but ethminer’s last release (2019) predates RTX 40/50 cards.
  1. 最简单：Windows + NVIDIA 显卡（RTX 20/30/40/50 系列）：下载 scdo-shard0-gpu-miner-windows-amd64.zip，解压到例如 C:\scdo-miner，在 Windows Defender 中把该文件夹加入排除项（所有 GPU 挖矿软件都会被标记为“可能不需要的应用”），用记事本打开 start-mining.bat，把 set WALLET=0x… 改成你的地址，然后双击运行。它会启动本地 core-geth 节点（奖励进入你的地址）和一个小型 Stratum 代理，从官方发布页下载 NVIDIA 挖矿软件 Rigel 1.23.2（校验 SHA256；闭源，开发者费 0.7%），节点同步完成后自动开始挖矿。Linux：scdo-shard0-gpu-miner-linux-amd64.tar.gz，运行 WALLET=0x… ./start-mining.sh。
  2. 手动 / 其他挖矿软件：首次初始化 ./core-geth-scdo-linux-amd64 --datadir ./scdo0 init scdo-shard0-genesis.json，运行节点（不要加 --mine）：
    ./core-geth-scdo-linux-amd64 --datadir ./scdo0 --networkid 5680 --port 30368 --syncmode full --bootnodes enode://1d2c370db7c419349e2313f20023f6b379f946990042b9b42df45cb56e4c3487df0d36c52cd81308fcdf312450f758a6213fcac21213e94a71af4a3c9392601f@82.223.19.88:30368 --http --http.addr 127.0.0.1 --http.port 8545 --http.api eth,net,web3,miner --miner.etherbase 0xYOUR_ADDRESS
    再运行安装包里的代理（节点同步完成后才开始 getwork 挖矿）：
    ./scdo-stratum -rpc http://127.0.0.1:8545 -listen 127.0.0.1:3333 -autostart -ref-rpc https://scdoscan.io/rpc/0
    然后把任意 Ethash Stratum 挖矿软件指向 127.0.0.1:3333，例如 rigel -a ethash -o ethproxy+tcp://127.0.0.1:3333 -u 0xYOUR_ADDRESS 或 lolMiner --algo ETHASH --pool 127.0.0.1:3333 --user 0xYOUR_ADDRESS --ethstratum ETHPROXY。
  3. 节点同步完成前不要挖矿，否则新节点会从创世块开始自建一条链。ethminer 等 getwork 挖矿软件仍可直接连接 http://127.0.0.1:8545，但 ethminer 最后一次发布是 2019 年，早于 RTX 40/50 系列显卡。

Each block pays the miner the standard Ethash block reward (2 SCDO) plus fees. This is a network-security function; SCDO makes no promise of earnings (see below).

每个区块按标准 Ethash 规则向矿工发放区块奖励（2 SCDO）及手续费。挖矿的目的是保障网络安全，SCDO 不作任何收益承诺（见下文）。

Before you start开始之前

  • You need a PC or server (Windows / Linux / macOS) that can stay online; phones are not suitable.
  • Mining uses electricity and hardware. Its purpose is to secure the network. SCDO makes no promise of earnings, rewards or returns from mining or running a node.
  • There is no mining pool: you mine solo against your own node. Only download node software from scdoscan.io (checksums provided) or build core-geth yourself, and never enter a wallet recovery phrase into mining or node software.
  • 需要一台可长期在线的电脑或服务器（Windows / Linux / macOS），手机不适用。
  • 挖矿会消耗电力与硬件，其目的在于保障网络安全。SCDO 不对挖矿或运行节点作出任何收益、奖励或回报承诺。
  • 目前没有矿池：你通过自己的节点单独挖矿。请只从 scdoscan.io 下载节点软件（提供校验值）或自行编译 core-geth，切勿在挖矿或节点软件中输入钱包助记词。
