Run an SCDO node / 运行 SCDO 节点

Full node + CPU solo miner for the SCDO legacy chain (shards 1–4), built from SCDOLAB/go-scdo (commit cd31d1c, same code as the public nodes). Bootstrap nodes are pre-configured. No wallets or private keys are included.
全节点 + CPU 单机挖矿（旧链分片 1–4），基于 SCDOLAB/go-scdo 源码编译，已预置引导节点，不含任何钱包或私钥。

Linux

curl -fLO https://scdoscan.io/downloads/node/scdo-node-linux-amd64.tar.gz
curl -fLO https://scdoscan.io/downloads/node/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS
tar xzf scdo-node-linux-amd64.tar.gz && cd scdo-node-linux-amd64
./start.sh 1                                   # sync shard 1 (1-4) / 同步分片 1
./start.sh --mine 1S01...your address... --threads 4   # solo-mine / 单机挖矿
./status.sh 1                                  # height & peers / 高度与连接数

Windows

Unzip scdo-node-windows-amd64.zip, then in that folder run start.bat 1 (sync) or start.bat --mine 1S01... --threads 4 (mine); status.bat 1 shows progress. The .exe files are unsigned — SmartScreen may ask for confirmation.
解压后在文件夹中运行 start.bat 1（同步）或 start.bat --mine 1S01... --threads 4（挖矿），status.bat 1 查看进度。exe 未签名，SmartScreen 可能提示确认。

macOS

Experimental: cross-compiled on Linux and not yet tested on a real Mac — feedback welcome. Intel (x86_64) build; on Apple Silicon (M1–M4) it runs via Rosetta 2 (the old Go 1.12 toolchain required by the consensus library has no native arm64 support). The binaries are not signed/notarized, so remove the Gatekeeper quarantine flag once after extracting.
实验性版本：在 Linux 上交叉编译，尚未在真实 Mac 上测试，欢迎反馈。本包为 Intel（x86_64）版本，Apple 芯片（M1–M4）通过 Rosetta 2 运行（共识库所需的 Go 1.12 不支持原生 arm64）。程序未经 Apple 签名/公证，解压后需先移除 Gatekeeper 隔离属性。

curl -fLO https://scdoscan.io/downloads/node/scdo-node-darwin-amd64.tar.gz
curl -fLO https://scdoscan.io/downloads/node/SHA256SUMS
grep darwin SHA256SUMS | shasum -a 256 -c
tar xzf scdo-node-darwin-amd64.tar.gz && cd scdo-node-darwin-amd64
xattr -dr com.apple.quarantine .               # Gatekeeper: allow unsigned binaries / 移除隔离属性
./start.sh 1                                   # sync shard 1 (1-4) / 同步分片 1
./status.sh 1                                  # height & peers / 高度与连接数

Notes / 说明

  • No address yet? ./scdo-client key --shard 1 creates one — keep the private key offline. / 没有地址？用 scdo-client key --shard 1 生成，私钥请离线保存。
  • First sync downloads the full shard history (millions of blocks, tens of GB, many hours). Mining pays only once synced. / 首次同步耗时较长，同步完成后挖矿才有收益。
  • Ports (shard 1/2/3/4): P2P 8057/8058/8059/8056 TCP+UDP (open for inbound if you can); RPC 8037/8038/8039/8036 stays on 127.0.0.1.
  • Shard0 (EVM, chainId 5680) runs core-geth (Ethash PoW): node binaries, genesis and README at /downloads/shard0/. / Shard0（EVM，chainId 5680）使用 core-geth，下载见 /downloads/shard0/。
