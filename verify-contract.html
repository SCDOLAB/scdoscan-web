How it works验证流程Verified contracts / 已验证合约

EN How automatic verification works

  1. KYC check. The signed message SCDO contract verification <address> <timestamp> proves which address is submitting. That address must be KYC-verified in the Shard 0 KYC registry, which stores only a status, tier, expiry and a record hash, never personal data. Not verified yet? Complete KYC in the SCDO web wallet (KYC tab).
  2. Compile. The server downloads the exact official solc release you chose (SHA-256 checked, cached) and compiles your source in a sandbox with your optimizer, runs and evmVersion settings.
  3. Compare. The compiled runtime bytecode is compared with eth_getCode on chainId 5680. immutable slots are masked and the metadata hash is compared separately: full match (identical) or partial match (only the metadata hash differs). Where the creation transaction is found, its creation code and constructor arguments are checked too.
  4. Publish. On a match the record is published at once. The contract page shows a "Contract: Verified" badge, the source, ABI and compiler settings, and a Read/Write panel. Your browser re-checks the on-chain code hash live each time the page is opened.

Limits: 2 MB per request, 1.5 MB of source, 60 s compile time, 12 submissions per hour per network. Verification is free; nobody will ask you for keys, seed phrases or a payment. Contracts on the archived legacy shards 1–4 are not covered. Details: /verified/METHOD.txt.

中文 自动验证流程

  1. KYC 检查：签名消息 SCDO contract verification <地址> <时间戳> 用于证明提交人地址。该地址须在 Shard 0 KYC 注册合约中为"已认证"。注册合约只存状态、等级、有效期和记录哈希，不存个人信息。尚未认证？请在 SCDO 网页钱包（KYC 页面）完成认证。
  2. 编译：服务器下载你所选的官方 solc 发布版（校验 SHA-256 并缓存），按你填写的优化器、runs 和 evmVersion 在沙箱中编译。
  3. 比对：将编译得到的运行时字节码与 chainId 5680 上的 eth_getCode 比对。immutable 位置会被屏蔽，元数据哈希单独比较：完全匹配（完全相同）或部分匹配（仅元数据哈希不同）。如能找到部署交易，还会核对创建字节码和构造函数参数。
  4. 发布：比对一致后立即发布。合约页面显示"Contract: Verified"标记、源码、ABI、编译参数和读/写面板。每次打开页面时，浏览器还会实时复核链上代码哈希。

限制：每次请求 2 MB、源码 1.5 MB、编译 60 秒、每个网络每小时 12 次提交。验证免费，任何人都不会向你索要私钥、助记词或付款。已归档的旧分片 1–4 上的合约不适用。详情：/verified/METHOD.txt。
